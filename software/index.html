Software Tools

Open-source tools developed by the Mangul Lab.

pyTCR

Active

A comprehensive Jupyter Notebook-based platform for T-Cell receptor (TCR) data analysis to facilitate reproducibility and rigor of immunogenomics research.

View on GitHub

UMI-Reducer

Active

A computational protocol allowing to differentiate PCR duplicates from biological duplicates using Unique Molecular Identifiers (UMIs), designed in collaboration with Prof. Kelsey Martin.

View on GitHub

VGA

Active

A computational method for the accurate de novo assembly of heterogeneous viral populations (viral quasispecies) from ultra-deep sequencing data.

Visit Website

Telescope

Active

An open-source web application that tracks the progress of jobs submitted to remote servers using Sun Grid Engine (SGE) on-demand scheduling system.

View on GitHub

SBT

Active

An open-source software platform to mine discarded and off-target clinical sequencing reads, enabling the discovery of prognostic biomarkers across cancer types.

View on GitHub

ImReP

Active

A computational method for rapid and accurate profiling of the adaptive immune repertoire from bulk RNA-Seq data.

View on GitHub

ROP

Archived

A computational protocol to discover the source of all reads, which originate from complex RNA molecules, recombined B and T cell receptors, and microbial communities in RNA-Seq data.

View on GitHub

Needle

Active

A method for comprehensive virome, mycobiome, and eukaryome profiling on the strain level, combining alignment and assembly strategies.

View on GitHub

MiCoP

Active

A high-accuracy computational tool for microbial community profiling, specifically designed to detect low-abundance viral and fungal organisms in metagenomic samples.

View on GitHub

Microbe-scope

Active

A computational tool to visualize metagenomics data in the form of interactive coverage plots, helping to detect false positives based on microbial genome coverage.

View on GitHub

HapIso

Active

A computational method to reconstruct the haploid transcriptome of a diploid organism from long single-molecule reads.

View on GitHub
